# Permitting and Code Compliance

Permitting is where a design meets the law. The authority having jurisdiction (AHJ) will not build what you drew until it's proven to comply with the adopted building code, zoning, fire, energy, and accessibility requirements. Rejections and redesigns here cost months and fees. The discipline is to design *to* the code from the start and submit a complete, self-proving package, not to submit hopefully and negotiate later.

## Establish the governing codes first

Identify exactly which codes and editions the jurisdiction has adopted — this varies by locality and year. Typically:

- **Building code**: the locally adopted edition of the International Building Code (IBC) or, for one/two-family homes, the International Residential Code (IRC). Jurisdictions adopt specific editions with local amendments — use the adopted edition, not the newest one.
- **Zoning ordinance**: use, setbacks, height, lot coverage, FAR, parking, landscaping. Zoning is separate from building code and often the first gate.
- **Fire code** (IFC), **energy code** (IECC or local, e.g. Title 24 in California), **accessibility** (ADA Standards + IBC Ch. 11 / ANSI A117.1), **plumbing/mechanical/electrical** codes, and any flood, seismic, or wildland-urban-interface overlays.

Confirm the local amendments — they routinely override the base code and are where first-time submitters get caught.

## Do the code analysis before drawing details

Produce a code analysis that drives the design:

- **Occupancy classification** (A, B, E, I, M, R, S, etc.) and mixed-occupancy handling.
- **Construction type** (I–V) and the resulting **allowable height and area**, including increases for sprinklers and frontage. Confirm the building fits — if not, add sprinklers, change type, or add fire separations.
- **Egress**: occupant load, number of exits, exit separation, travel distance, common path, corridor width, stair sizing, door swing, and exit discharge.
- **Fire resistance**: rated assemblies, separations between occupancies, shaft and corridor ratings, opening protectives.
- **Accessibility**: accessible route, entrances, restrooms, clearances, parking, and reach ranges.
- **Energy**: envelope, glazing, insulation, and systems compliance path (prescriptive vs performance).

Put this analysis on the drawings as a code-summary sheet. Reviewers approve faster when you've shown your work and cited the sections.

## Assemble a complete permit package

Incomplete submissions are the most common cause of delay — many rejections are administrative, not design. A typical package: architectural drawings (site, plans, elevations, sections, details), structural, MEP, and civil drawings as required, the code-analysis sheet, energy compliance documentation, accessibility details, specifications, and required calculations. Include whatever the jurisdiction's submittal checklist demands (application forms, fees, surveys, geotech, stormwater/SWPPP, title). Coordinate the consultants' drawings so they don't contradict each other — cross-discipline conflicts trigger comments.

## Work the review process

- **Pre-application meeting**: for anything non-trivial, meet the building/planning department early to surface concerns before you've drawn everything. This prevents the expensive surprise.
- **Anticipate the comments**: expect a plan-review comment letter. Respond to every comment point-by-point with a written response and a revised drawing reference. Address the reviewer's actual concern; don't argue reflexively, but do cite code when you're right.
- **Special approvals**: zoning variances, conditional use permits, historic/design review, and variances take their own timelines with public hearings — start these early and in parallel, as they often gate the building permit.
- **Track the schedule**: know the jurisdiction's review turnaround and plan around it. Keep the client informed of realistic permit timelines — optimism here erodes trust.

## Quality bar and failure modes

Great: the correct adopted codes and amendments identified, a rigorous code analysis embedded in the drawings, a complete coordinated submittal, pre-app alignment with the AHJ, and approval in one or two review cycles with clean point-by-point comment responses. Acceptable: compliant design, complete package, approval within normal cycles. Failing: designing to the wrong code edition, ignoring local amendments, missing zoning or accessibility drivers until review, an incomplete package that bounces administratively, uncoordinated consultant drawings, or discovering a variance is needed after the design is locked.
